# 青梧宮廷仕途系統 v1（palace-career）

## 調研摘要（改編用，面向玩家文案用青梧／景安）
- **九品十八階**：正／從一至九品；文散階光祿大夫…登仕佐郎；武散階建威將軍…修武佐校尉。
- **太監品級**（清・敬事房）：最高四品宮殿監督領侍 → 五品宮殿監正侍 → 六品宮殿監副侍 → 七品執守侍 → 八品侍監；遊戲簡化為五級。
- **宮女**：選秀入宮 → 女官（夫人／淑儀／婉侍／柔婉等品秩）。遊戲：宮女→女史→女官→婉侍→淑儀（可走貴妃／帝側支線）。
- **參考玩法**：《叫我官老爺》政績升官＋解鎖權能；橙光宮廷好感／服侍；本遊戲既有帝心／宮熱／廠衛線。

## 核心循環
探索宮殿場景功能 → 領取／完成朝務任務 → 得**朝廷威望 courtPrestige** → 升品 → 解鎖權能（議政／服侍／換文武）→ 好感／交易副作用。

## 權能解鎖
| 條件 | 權能 |
|------|------|
| 任一 track 入仕 | 宮籍腰牌、內廷通行加強 |
| 文／武 pin≤5（五品以上） | 換文武官（耗威望 30） |
| 文／武 pin≤3 | **上殿議政**（太和殿／乾清宮） |
| 太監 grade≥3 | 可自請調殿 |
| 太監／宮女 grade≥4 或 文武 pin≤4 | **選擇服侍** 景安帝／沈貴妃／假太后／建寧郡主 |
| 權貴好感≥60 且 favor backdoor | 可破格升一階（每目標每季一次） |

## 任務樞紐
地點：**乾清宮**（吏部票擬意象）＋外廷快捷入口「朝廷仕途」面板。
任務池 COURT_QUESTS：按場景／track 過濾；完成給威望＋少量金／經驗／好感／善惡。

## 場景功能（每宮點）
見 `PALACE_LOC_FEATURES`：標籤＋專屬行動＋駐場小 NPC 名（寫意）。

## 賄賂交易
官途中每日低機率 `pendingDeal`：收金／藥／通行 ↔ 做髒事（扣俠義／加惡／升宮熱）。可拒。

## IP
皇帝＝景安帝；後宮＝沈貴妃、建寧郡主、毛東珠影（假太后）等既有 ID。無真實清帝名、無金庸真名。

## 自測清單
1. 入宮 → 擇業（文／武／宮女／淨身）
2. 乾清宮領任務 → 目標場景完成 → 威望升 → 升品
3. 淨身房自願寫意入籍 → 隨機分殿 → 太監任務升階
4. 接受／拒絕 pendingDeal
5. 高好感 favor 破格升；三品議政
