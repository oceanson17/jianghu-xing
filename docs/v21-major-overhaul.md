# 江湖行大改 v21（2026-10-19）

致敬群俠傳玩法手感；人名／門派／地名皆為**青梧原創致敬名**，不使用金庸作品原名或真實清帝號。

## 目標
1. **物品**：種類（kind）／用途／來源標示；擴充道具；送禮；背包分類優化
2. **好感＋追求**：統一 `npcFavor`；送禮／交談累積；高好感 NPC 主動追求；接／拒寫入命運與情緣
3. **劇情**：多條新支線與場景機緣（邊關、藥谷、破碗、蒼峰、煙港、無音等）
4. **群俠式地圖**：世界圖可點 pin；地點顯示在場 NPC 頭像；合理分佈（僅用現有／致敬名）
5. **武功**：熟練度／心法／練功／門派潛修；威力隨熟練提升

## 存檔
- `saveVer` ≥ 11；自動遷移 `npcFavor`／`skillMastery`／物品 meta 旗標
- 舊檔不需清

## 入口
- 地圖：群俠式 pin＋NPC 臉
- 背包：種類篩選＋來源／用途小字
- 角色：武功熟練度＋練功入口（營地／門派地）
- 對話：送禮、好感條；高好感觸發追求事件
- 任務簿：新支線自動登錄
