# 寫意上限・淨身／東廠／身體狀態 v15

## 尺度（硬規則）
- **禁止**：殘忍細描、糞穢、酷刑細節、成人行為、18禁模式、AI 情色生成。
- **允許**：寫意後果（善惡／廠熱／好感／氣血／定力／魅力）、抽象差事選項、身體狀態標籤影響數值。

## 女角淨身修復
- 僅 **男身**（`isMale()`）可淨身／太監籍。
- 女扮男裝 **不可** 妄入淨身房；可走【喬裝騙過督公】入廠（不經太監籍）。
- 舊檔若出現「女太監」會自動矯正清旗。

## 男・太監籍入東廠
1. 先淨身房寫意入籍（`eunuch` + bodyTag `castrated`）
2. 廠衛司【以太監籍求入廠】→ **廠公驗身（寫意 pass/fail）**
3. 通過後選差事（只改數值）：
   - 抄黑冊／值夜／不堪差事（善惡最多 −50・僅一次）
   - **拒絕** →『誤闖東廠受罰』：氣血↓、定力↓、魅力↓、手傷／瘀傷標籤

## 身體狀態 `S.bodyTags`
| 標籤 | 效果（摘要） |
|------|----------------|
| castrated | 武力／身法／魅力↓（寫意） |
| injured_hands | 差事成功率↓；取悅貴人易失敗→宮熱 |
| limp / bruised / shaken / veiled_scar | 戰鬥／魅力／定力微調 |

【侍奉】取悅貴人＝奉茶整衣寫意檢定，**無成人描寫**。
