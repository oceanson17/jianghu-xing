# 任務自動導航 v24（2026-10-19）

## 目標
任務簿**一鍵導航**至目標地；清楚**下一步**提示；抵達後可**自動開啟**相關 NPC 對話／朝廷交付／民間機緣。

## 入口
- 任務簿卡片「🧭 導航」「追蹤」
- 任務簿頂部「導航當前任務」
- 地圖橫幅「🧭 導航」
- 各地行動「【導航】前往／繼續…」

## 行為
| 項目 | 說明 |
|------|------|
| 導航 | 旅行至任務目標地（多地點可選） |
| 追蹤 | 設為當前焦點，地圖一鍵導航 |
| 下一步 | 卡片顯示 tip＋地點＋見誰／交付 |
| 自動開啟 | 抵達後：朝廷→交付確認；民間→機緣；有 NPC→對話；否則顯示下一步旁白 |
| 開關 | 任務簿「自動開啟：開／關」 |
