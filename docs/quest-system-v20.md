# 任務系統大幅優化 v20（2026-10-19）

## 目標
清晰的**任務簿**：主線／支線／朝廷／民間／AI 分類；追蹤、進度條、獎勵預覽、交付、失敗／過期、卡任務修復；AI 生支線接入劇情板。

## 入口
- 地圖橫幅旁「任務簿」
- 情緣頁頂部「打開任務簿」
- 更多 → 任務
- 各地「【任務簿】…」快捷行動

## 功能
| 項目 | 說明 |
|------|------|
| 追蹤 | 地圖／情緣顯示當前主目標一行字 |
| 進度 | 卡片進度條＋步驟提示＋目標地點「前往」 |
| 朝廷 | 領取時可見時限（預設 7 日）；過期扣威望；同地「交付」 |
| 民間 | 顯示當前地點可觸發的 CIV 機緣 |
| AI | 任務簿「請 AI 生支線」→ 劇情板；`npc_quest`／支線寫入任務簿 |
| 修復 | 清除無定義朝廷差、合併重複差、過期、主線卡步驟、三證據卡關等 |
| 獎勵 | 朝廷差獎勵預覽；交付記入 `questRewardLog` |

## 自測
`node scripts/autorun_v20_headless.js` → `window.__JH_V20_SELFTEST()`

任務簿手感致敬群俠傳；人名門派為青梧原創，不使用金庸原名／真實清帝號。
