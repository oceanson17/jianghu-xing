# 戰鬥處置 v17（2026-10-18）

## 功能
1. **戰敗**：非致命戰敗時，由 AI（DeepSeek＋離線後備）依勝者 NPC 身分／性格裁決處置：放走、訓斥、搜銀、關押、廠拿、驅離、帶傷等，**真改**存檔。寫意，無血腥／色情細描。
2. **戰勝**：對人形對手或具名 NPC，彈出「如何處置」自由輸入＋快捷；AI 執行放走／嚇退／搜銀／打傷／制住／送官／同行／了結（只改命運）等 mutator。
3. **設定入口**：`更多` 頁頂部醒目區塊「設定・作弊台」（與 DeepSeek API 設定分開標示）。

## 自測
`node scripts/autorun_v17_headless.js`
